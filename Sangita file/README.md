# HomoeoCare frontend preview

This project is a static, frontend-only storefront demo. It contains no application server, API, database, or backend service. Demo shopping-bag items, saved products, sample profile details, and sample appointment bookings are stored in the browser's local storage on this device.

## Open the preview

- Double-click `start.bat`, or
- Open `index.html` directly in a modern browser.

No Python, Node.js, database, package installation, or internet connection is required. The shop uses a bundled sample catalogue and system fonts.

## Preview interactions

- Browse and search the sample medicine catalogue; filter by category, brand, price, stock, and rating.
- Sign in with any email and non-empty password for a sample profile, or create a local demo profile.
- Add products to the sample bag and adjust quantities; save products to the wishlist.
- Preview sample doctor availability and create or cancel local demo bookings.

## Important

This is a visual and interaction prototype, not an online shop or booking service. Sign-in is not real authentication; passwords are not checked or saved. No appointment is sent to a doctor, and no product order or payment is placed. Browser storage is not secure account storage. Clearing this browser's site data clears the saved demo state.

Connect a trusted backend, authentication service, clinic scheduling system, and payment provider before handling real customers or medical information. Sample products and doctor profiles are placeholders, not medical advice or verified clinical information.
